# รายการบั๊กที่พบ (รอเลือกแก้) — ตรวจรอบ 24 ต.ค. 2569

ตรวจทั้งระบบ 4 ด้าน: ฐานข้อมูล (migration 0001–0021 + `supabaseApi`), งานหน้าคลัง (รับของ/ป้าย/ย้าย/สแกน/มือถือ), เบิก–FM-P-005–บัญชีคุม–ปิดเดือน–วันที่, และเดินใช้งานจริงบนเบราว์เซอร์ (มือถือ 390 px / คอม 1366 px)
ทุกข้อด้านล่าง **จำลองซ้ำได้จริง** — ข้อฐานข้อมูลรันบนฐานข้อมูลจำลองที่ลง migration จริงทั้งชุด, ข้อหน้าจอยืนยันจากโค้ดและภาพหน้าจอ · ข้อที่ต้องใช้งานพร้อมกันหลายเครื่องยืนยันบน PostgreSQL 16 แยกต่างหาก

**ยังไม่ได้แก้ข้อใด** — เลือกเลขข้อที่ต้องการให้แก้ (เช่น "แก้ A1 A2 B1 B2") · ข้อที่ต้องตัดสินใจเชิงนโยบายมีคำถามกำกับไว้

ระดับ: 🔴 วิกฤต/สูง (ยอดผิดหรือของเสียหลุดเข้าไลน์) · 🟠 กลาง · 🟡 ต่ำ
