## 2. ตั้งค่าระบบ (หลังบ้าน)

เริ่มที่ **หลังบ้าน → พร้อมใช้จริง** (แท็บแรกของผู้ดูแลระบบ): ระบบตรวจจากข้อมูลจริงว่ายังขาดอะไร — บัญชีผู้ใช้ตามบทบาท, ช่องเก็บตามผัง, ป้ายช่อง, BOM, ยอดเปิดคลัง, โหมดใช้งานจริง (+ ข้อแนะนำ: หัวหน้าโซน, รหัส UAM, กฎโซน) · แต่ละข้อมีปุ่มพาไปหน้าที่ใช้ทำ

| ขั้น | ที่ไหน | ทำอะไร |
|---|---|---|
| 2.1 | หลังบ้าน → ผู้ใช้งาน & ประวัติเข้าใช้ | เพิ่มบัญชี พี่เต็มดวง (เจี๊ยบ), ทีมคลัง, Planning (บทบาท *วางแผน*), ผู้รับทราบฝั่งบัญชี (ค่าเริ่มต้นคือ *ผู้จัดการ*) |
| 2.2 | หลังบ้าน → หัวหน้าโซน | "ใช้คนเดียวทุกโซน" → เลือกพี่เต็มดวง → **ตั้งทั้ง N โซน** |
| 2.3 | หลังบ้าน → นำเข้าข้อมูล (Excel) → Part / รหัส UAM | **ดาวน์โหลดแบบฟอร์ม** → เติมคอลัมน์ *รหัส UAM* → **อัปโหลดไฟล์** → ตรวจ (แถวสีแดง = ผิด) → บันทึก |
| 2.4 | หลังบ้าน → นำเข้าข้อมูล (Excel) → BOM ชุดวงล้อ | ดาวน์โหลดแบบฟอร์ม → 1 ชุด (รหัส FG เช่น 2019333) หลายแถว: part + จำนวนต่อ 1 วง → อัปโหลด → บันทึก |
| 2.5 | หลังบ้าน → สิทธิ์ตามบทบาท | ตรวจกลุ่ม "บัญชีคุม": ปิดยอด (ผู้จัดการ), รับทราบ Planning (วางแผน), รับทราบบัญชี (ผู้จัดการ) |
| 2.6 | หลังบ้าน → โหมดระบบ | **ล้างข้อมูล (เก็บถาวร)** ให้ข้อมูลทดสอบเก่าไม่ปนกับรอบนี้ (พิมพ์ "ล้างข้อมูล" ยืนยัน · ข้อมูลเก่าเก็บเป็นชุด กู้คืนได้) |
| 2.6b | หลังบ้าน → สิทธิ์ตามบทบาท | กลุ่ม "รับของ": **ยกเลิกใบรับ (GRN)** — ค่าเริ่มต้นให้ผู้จัดการ (ผู้ดูแลระบบได้ทุกสิทธิ์) · เพิ่มให้หัวหน้าคลังได้ถ้าต้องการ |
| 2.7 | หลังบ้าน → ข้อมูลหลัก → ช่องเก็บ | เลือกโซน → **พิมพ์ป้าย QR ช่อง** (A4 สติกเกอร์ 3×8 ดวง 70×37 มม. หรือกระดาษธรรมดาแล้วตัด) → ติดที่ช่อง · ตอนจัดเก็บ/ย้าย สแกนป้ายกล่องแล้วสแกนป้ายช่อง ระบบใส่ช่องปลายทางให้เอง |

## 3. งานประจำวันระหว่างทดลอง

เริ่มทุกวันที่ **งานวันนี้** (มือถือ: เมนู *งาน* ซ้ายสุด เปิดมาเจอเลย · คอม: งานคลัง → *งานวันนี้*) — เห็นเฉพาะงานตามสิทธิ์ของแต่ละคน แตะรายการแล้วเปิดหน้าสแกนที่กล่องนั้นและงานนั้นทันที

- **รอตรวจ MI3** → แตะ = สแกนโหมดผลตรวจ MI3 · **จัดเก็บเข้าช่อง** (กล่องที่จุดรับของ / ผ่าน MI3 แล้ว) → แตะ = โหมดจัดเก็บ · **NG รอส่งคืน** → แตะ = โหมดเบิก NG
- **นับวนวันนี้**: ระบบเลือกช่องที่มีของวันละ ~1/20 (5–30 ช่อง) ให้นับครบทุกช่องในราว 1 เดือน · ลำดับ: ครั้งก่อนไม่ตรง → ยังไม่เคยนับ → เข้า-ออกบ่อย → นานสุด · แตะช่อง → กล่อง → **นับ**
- จอคอมมีเพิ่ม: รออนุมัติปรับยอด · คิวพิมพ์ · Invoice ยังรับไม่ครบ · ปิดยอดรอรับทราบ (กดแล้วไปแท็บนั้น)
- เสียง + สั่นตอนสแกน: เจอป้าย = ติ๊ด · สำเร็จ = เสียงขึ้น · นับไม่ตรง = ติ๊ดสองครั้ง · ผิดพลาด = เสียงต่ำยาว (สั่นได้เฉพาะ Android) · ปิดได้ที่ปุ่ม 🔊 ในหน้าสแกน

1. **รับของ** → ดูหัวข้อ *รับของด้วยใบตรวจรับ* ด้านล่าง (รหัสมี /A /B ระบบตัดเอง)
2. **เบิกเข้าไลน์ ระหว่างวัน** เลือกทางใดทางหนึ่ง (ทั้งสองทางเป็นใบเบิกย่อยเหมือนกัน):
   - ที่คอม: เบิกเข้าไลน์ → เลือก Model → ชุดวงล้อ → จำนวนวง → คำนวณ → บันทึก (ตัดจากกล่องที่เข้าก่อน)
   - ที่ชั้นวาง (มือถือ): สแกน → **เบิก** → เลือก *เข้าไลน์* + Model + เลขใบเบิกกระดาษ → สแกนทีละกล่อง (เลขใบเบิกเดียวกัน = ใบเดียวกัน) · *QC เบิก* / *NG / ส่งคืน* ลงช่องของตัวเองในบัญชีคุม
3. **จบวัน FM-P-005**: แท็บ FM-P-005 ยอดรวมจบวัน → ใส่เลขที่เอกสาร → แก้เฉพาะช่องที่ต่าง → บันทึก (นับใบที่สแกนเบิกรวมแล้ว ไม่ตัดซ้ำ)
4. **ส่ง Planning**: แท็บสรุปส่ง Planning → Export Excel

**รับของด้วยใบตรวจรับ** (คอม: งานคลัง → *1 รับสินค้า / ตรวจรับ* · มือถือ: เมนู *รับของ*)

1. ถ่าย Packing List (AI อ่าน Part · จำนวน · **เลขเคส/พาเลท**) + Invoice → ตรวจหัวเอกสาร Model และเลขเคส (แก้ในช่อง *เคส* ได้) → **สร้างใบตรวจรับ → ตรวจทีละเคส**
2. ตรวจของทีละเคส ทั้งมือถือและคอม หลายคนแบ่งเคสกันตรวจใบเดียวกันได้ (เห็นผลของกันและกันภายใน ~15 วินาที · ปุ่ม ↻ โหลดทันที)
   - ของในเคสตรงตาม PL ทั้งหมด → **✓ ทั้งเคสตรงตาม PL** (บันทึกเฉพาะบรรทัดที่ยังไม่ตรวจ)
   - ทีละบรรทัด: **✓ ตรง** หรือใส่จำนวนที่นับได้ → **บันทึก** (บรรทัดที่บันทึกแล้วไม่มีปุ่ม ✓ ตรง ให้กดทับ · แก้ตัวเลขแล้วกดบันทึกใหม่)
   - ของเสียหาย / หมายเหตุ / รูปหลักฐาน → *เสียหาย / หมายเหตุ / รูป* (จำนวนเสียหายนับรวมอยู่ในยอดที่นับได้ · ตอนออก GRN แยกเป็นกล่อง NG ให้เอง)
   - เคสไม่มากับรถ → **ไม่มีเคสนี้มา** · เจอของที่ไม่มีใน PL → *+ พบของที่ไม่มีใน PL ในเคสนี้*
   - AI อ่าน Part / ยอด PL / เลขเคสผิด → *✎ แก้ข้อมูลจาก PL* (ไม่แตะผลตรวจ)
   - *เทียบ Invoice*: ยอดรวมต่อ part นับได้ vs Invoice · AI อ่าน Invoice ได้แค่หัว → **ใส่ยอด Invoice** เอง
3. ตรวจครบ → **ตรวจครบ → ออก GRN**: รับเข้าตาม**ยอดที่นับได้จริง** · 1 เคส = 1 กล่อง/ป้าย (part ที่ต้องตรวจ MI3 แยกกล่องละ part)
   - **ของเสียหายแยกเป็นกล่อง NG อัตโนมัติ** (1 กล่องต่อ part) อยู่ที่พื้นที่กัก NG (NG-HOLD) · ป้ายพิมพ์แถบดำ "NG · ของเสียหาย · ห้ามเข้าไลน์" → แยกของไปวางที่พื้นที่ NG
   - กล่อง NG ขึ้นใน *งานวันนี้ → NG รอส่งคืน* · ส่งคืน RE แล้วตัดยอดด้วย *เบิก → NG / ส่งคืน* (บัญชีคุมลงช่อง NG)
   - ของในพื้นที่กัก NG ไม่ถูกตัดตอนเบิกเข้าไลน์ / QC / FM-P-005 · สแกนเบิกเข้าไลน์จากกล่อง NG ไม่ได้ (หน้าสแกนเตือนให้เลือก "NG / ส่งคืน" หรือ "QC เบิก")
4. มีของไม่ตรง → **🖨️ รายงานผลตรวจรับ** (A4: รายการไม่ตรงรายเคส · เทียบ Invoice · รูปหลักฐาน · ช่องเซ็น) แนบส่ง RE / เก็บแฟ้ม
5. ป้าย QR พิมพ์หรือไม่ก็ได้: ไม่พิมพ์ = ค้นด้วยเลข PL + เลขเคส เช่น `55035596 F28` ที่หน้า *ค้นหา/ย้าย* หรือช่องค้นหาบนจอคอม
- ใบที่ยังตรวจไม่ครบอยู่ใน *งานวันนี้ → ใบตรวจรับค้าง* และ *รับของ → ใบตรวจรับ · ค้าง N* · ยกเลิกทั้งใบได้ (ใส่เหตุผล) ถ้ารถเที่ยวนั้นไม่มา
- แบบเดิม (กรอกยอดแล้วรับเลย) ยังใช้ได้: เลือก *กรอกยอดนับที่นี่แล้วรับเลย*

**ย้าย / จัดเก็บโดยไม่ต้องสแกน** (คอม: งานคลัง → *4 ย้าย / จัดเก็บ* · มือถือ: *ค้นหา/ย้าย* → *ย้ายของ (ไม่ต้องสแกน)* · หรือ *งานวันนี้ → จัดเก็บเข้าช่อง → เลือกหลายกล่องแล้วย้ายทีเดียว*)

1. ค้นกล่อง: เลขป้าย / Part / เลข PL + เคส / ช่อง (พิมพ์หลายคำได้) · กรอง *ที่จุดรับของ* / *ที่จุดตรวจ MI3*
2. ติ๊กเลือกหลายกล่อง (หรือ *เลือกทั้งหมด*)
3. ปลายทาง: ช่องที่ระบบแนะนำตามกฎโซนตอนนี้ · หรือเลือกโซน → แตะช่อง (เห็นว่าว่าง/มีกี่กล่อง) · หรือพิมพ์รหัสช่อง
4. **ย้ายไป …** → ยืนยัน · ระบบบันทึกว่าย้าย "จากรายการ" (แยกจากการสแกน หัวหน้าตรวจย้อนหลังได้) · สแกน QR แบบเดิมยังใช้ได้

**ยกเลิกใบรับ (GRN)** — กดรับไปแล้วแต่ผิด (Model ผิด, นับผิด, รับซ้ำ): *ป้าย QR & พิมพ์* → เลือก GRN → **ยกเลิกใบรับ** → ใส่เหตุผล

- กล่องทุกกล่องของใบนั้นใช้ไม่ได้ (แกะป้ายที่แปะแล้วออก) · บัญชีคุมไม่นับรับเข้าของใบนั้น · เลข GRN ไม่ถูกใช้ซ้ำ · งานพิมพ์ที่ค้างในคิวถูกยกเลิก
- ใบที่ออกจากใบตรวจรับ: ใบตรวจรับเปิดกลับมาพร้อมผลตรวจเดิม → แก้ → ออก GRN ใหม่
- ยกเลิกไม่ได้ถ้าของจากใบนั้นถูกเบิก / ตรวจ MI3 / แก้ยอดแล้ว, รวมกล่องกับของใบอื่น หรือเดือนนั้นปิดยอดแล้ว ⇒ ใช้ตรวจนับ & ปรับยอดแทน

แต่ละงานมีที่ทำที่เดียว: ตรวจนับ/แก้ไขยอดและการอนุมัติทั้งหมดอยู่ที่ **งานคลัง → 8 ตรวจนับ & อนุมัติ** · ผัง 3D และช่องค้นหาด้านบนใช้ข้อมูลคลังชุดเดียวกับมือถือ (หน้า "สต็อก (ตัวอย่างเดิม)" เอาออกแล้ว)

**หาที่ว่าง / หาของ: ผังคลัง 2D** (คอม: เมนู *ผังคลัง 2D* · มือถือ: แท็บ *ผัง*) — บนจอคอม คลัง / MI3 / ผลิต เข้าระบบแล้วเจอหน้านี้ก่อน (มือถือเจอ *งานวันนี้* ก่อน)

1. เลือกชั้น (A ชั้น 1–3, F ชั้น 1 / ชั้นลอย / ชั้น 2, ลานนอกอาคาร) — ทีละชั้น ไม่ซ้อนกัน
2. สีช่อง: ขาว = ว่าง · น้ำเงิน = มีของ · ส้ม = รอตรวจ MI3 (ห้ามเบิก) · ลายเทา = ปิดใช้ · บนผังแต่ละช่องแบ่งแถบตามชั้น (ซ้าย → ขวา = ชั้นล่าง → บน)
3. แตะโซน → หน้า rack ทีละแถว (ชั้น × ที่วาง ตัวอักษร = Model) → แตะช่อง → กล่องในช่อง + ปุ่มเปิดหน้าสแกน · แท็บ *เส้นทางเดิน* บอกทางจากจุดเริ่ม
4. ค้นหาเลขป้าย / Part / ช่อง → เปิดโซนที่มีของมากสุด ช่องที่มีของที่ค้นหาขอบแดง (จุดแดงบนแท็บชั้นที่มีของ)

**ภาพรวม (ผู้บริหาร)**: เมนู *ภาพรวม* บนจอคอม — เลือกช่วง วันนี้ / 7 วัน / เดือนนี้ และเลือก Model ได้ ทุกตัวเลขในหน้าเปลี่ยนตาม

- ตัวเลขหลัก: ของดีคงคลัง · **ความแม่นยำสต็อก** (เทียบเป้า 98%) · ช่องเก็บที่ใช้ · รอตรวจ MI3 · NG รอส่งคืน · รับเข้า · เบิกเข้าไลน์
- ตาม Model: คงเหลือ รับ เบิก ใช้เฉลี่ยต่อวัน และ **พอใช้กี่วัน** (part ที่จะหมดก่อน · แดง < 3 วัน · เหลือง < 7 วัน · คิดจากยอดเบิก 14 วันล่าสุด)
- รายการเตือน: ใกล้หมด · รอ MI3 เกิน 2 วัน · กล่องค้างเกิน 30 วัน · กล่องนอกช่องผัง · รออนุมัติ · ยังไม่ปิดยอด
- กดรายการเตือน / Model / โซน / ชั้น → เปิด **ผังคลัง 2D** ที่จุดนั้นและไฮไลต์กล่อง (ล้างไฮไลต์ที่ปุ่ม × ในช่องค้นหา) · เรื่องอนุมัติ/ปิดยอด → เปิดแท็บในงานคลัง

ผังโรงงาน 3D (ผู้จัดการ / วิศวกร / วางแผนเจอหน้านี้ก่อน): *ภายในอาคาร* ดูทีละชั้น เลือก *ทุกชั้น* เพื่อดูซ้อนกันแบบเดิม · สลับ 2D ↔ 3D ได้ที่ปุ่ม *ดูใน 3D* / *ดูช่องเก็บในผังคลัง 2D*

## 4. ตรวจนับ / อัปเดตยอดคงเหลือ

นับทีละกล่อง (**นับแบบไม่เห็นยอด**): สแกน → **ตรวจนับ / แก้ไขยอด** → หน้าจอไม่โชว์ยอดในระบบ → นับของจริงแล้วใส่จำนวน → **บันทึกการนับ** → ระบบบอกผล
- ตรง → เสร็จ · ไม่ตรง → ระบบบอกยอดในระบบ → **นับซ้ำอีกครั้ง** → ยังได้เท่าเดิม → เลือกเหตุผล → **ส่งขอปรับยอด** → ผู้อนุมัติกดที่แท็บ 8
- **ความแม่นยำสต็อก** (หน้าภาพรวม) = รายการที่นับครั้งแรกของวันแล้วตรงกับระบบ ÷ ที่นับทั้งหมด · เป้า ≥ 98% (ต่ำกว่าเป้าและนับ ≥ 5 รายการ ⇒ ขึ้นในรายการเตือน) · ใบตรวจนับ Excel ไม่นำมาคิด (ใช้ตั้งยอดเปิดคลัง)

นับทั้งโซน (Excel):

1. งานคลัง → **ตรวจนับ & อนุมัติ** → เลือกโซน + ระดับ (รายช่องเก็บ แนะนำ) → **ดาวน์โหลดแบบฟอร์ม** (มียอดในระบบให้แล้ว)
2. นับจริง กรอกคอลัมน์ "นับได้" (เว้นว่าง = ไม่ได้นับ, 0 = ไม่มีของ) · เจอของนอกรายการ เพิ่มแถวเอง
3. **อัปโหลดผลนับ** → ตรวจ ขาด / เกิน / ผิด → ใส่หมายเหตุ → **ส่งขออนุมัติ** (ยังไม่ปรับยอด)
4. ผู้มีสิทธิ์อนุมัติแก้ไขยอด (ผู้จัดการ/วิศวกร · ต้องไม่ใช่คนส่ง) → คิว **รออนุมัติปรับยอด** (คิวเดียวทั้งคำขอจากสแกนและใบ Excel · แท็บมีตัวเลขเตือน) → **อนุมัติ → ปรับยอด**
   - ขาด: ลดจากกล่องที่เข้าก่อน · เกิน: เพิ่มเข้ากล่องล่าสุด หรือสร้างกล่องใหม่ (พิมพ์ป้ายที่ ป้าย QR & พิมพ์ เลขเอกสาร CNT)
   - บัญชีคุม FM-P-537 แสดงเป็นบรรทัด "ปรับยอด" อ้างเลข CNT
   - ถ้ามีการเบิก/ย้ายหลังส่งจนยอดไม่พอลด ระบบไม่ให้อนุมัติ ⇒ ไม่อนุมัติแล้วนับใหม่

## 5. สิ้นเดือน

1. วันที่ 1 ของเดือนถัดไป: บัญชีคุม FM-P-537 → เลือก Model + เดือน → **ปิดยอด**
2. Planning และบัญชีเข้าแท็บเดียวกัน (มีตัวเลขแดงเตือน) → **รับทราบ**
3. Export Excel: sheet สรุปมีชื่อผู้ปิดยอดและผู้รับทราบ
4. ต้องแก้ย้อนหลัง → **เปิดเดือนเพื่อแก้ไข** (ระบุเหตุผล) → แก้ → ปิดยอดใหม่ (การรับทราบเริ่มใหม่)

## 6. เริ่มใช้งานจริง แล้วค่อยนำเข้ายอดยกมา

ข้อมูลทดลอง (รอบ 1–3) แยกจากของจริงเด็ดขาด เปลี่ยนเป็นใช้งานจริงแล้วไม่เห็นข้อมูลทดลอง ไม่ต้องลบอะไร
ข้อมูลหลัก (Part, รหัส UAM, BOM, ผู้ใช้, สิทธิ์, หัวหน้าโซน, ผัง) ใช้ชุดเดียวกันทุกโหมด
ถ้าเผลอลองใช้ในโหมดใช้งานจริงไปแล้ว: หลังบ้าน → โหมดระบบ → **ล้างข้อมูล (เก็บถาวร)** ให้โหมดจริงเริ่มจากว่างก่อนข้อ 2

1. หลังบ้าน → โหมดระบบ → เปลี่ยนเป็น **ใช้งานจริง** (ป้ายมุมบนเป็นสีเขียว "ใช้งานจริง")
2. เริ่มรับของจริง / พิมพ์ป้าย / จัดเก็บ ตามปกติ
3. นำเข้ายอดของที่มีอยู่เดิมเมื่อพร้อม: งานคลัง → ตรวจนับ & อนุมัติ → Excel นับทีละโซน
   - กรอก "นับได้" = **ของทั้งหมดที่อยู่จริง** ในช่อง/โซนนั้น (รวมของที่รับเข้าระบบไปแล้ว) ระบบเพิ่มเฉพาะส่วนที่ขาดให้เป็นกล่องใหม่ เลขเอกสาร CNT
   - ผู้อนุมัติ (คนละคนกับผู้ส่ง) กดอนุมัติ → พิมพ์ป้ายกล่องใหม่ที่ ป้าย QR & พิมพ์ (เลข CNT)
4. ข้อควรระวังระหว่างยังไม่นำเข้ายอดเดิม
   - เบิกของเก่าที่ยังไม่อยู่ในระบบไม่ได้ (ระบบแจ้งสต็อกไม่พอ) ⇒ นำเข้ายอดโซนที่ต้องเบิกบ่อยก่อน
   - บัญชีคุม FM-P-537 แสดงยอดนำเข้าเป็นบรรทัด "ปรับยอด" ในเดือนที่นำเข้า (เดือนถัดไปกลายเป็นยอดยกมา) ⇒ ถ้าทำได้ นำเข้าให้เสร็จในวันแรก ๆ ของเดือน

## 7. ล้างข้อมูล (เก็บถาวร) และกู้คืน

หลังบ้าน → โหมดระบบ (เฉพาะผู้ดูแลระบบ) ใช้ได้ทั้งโหมดทดลองและใช้งานจริง ทำกับ **โหมดที่เปิดอยู่ตอนนั้น** เท่านั้น

- **ล้าง**: ดูจำนวนข้อมูลของโหมดนี้ → ล้างข้อมูล… → ใส่หมายเหตุ (ไม่บังคับ) → พิมพ์ `ล้างข้อมูล` → ยืนยัน
  - ย้ายใบรับสินค้า กล่อง สต็อก ใบเบิก ประวัติเคลื่อนไหว Invoice ใบตรวจนับ ปิดยอดเดือน และคิวพิมพ์ ไปเก็บเป็น "ชุดที่ N" ไม่มีการลบ
  - ข้อมูลหลัก (Part, BOM, Model, ผัง, ช่องเก็บ, ผู้ใช้, สิทธิ์, ค่าตั้ง) อยู่ครบ
  - เลขเอกสารเดินต่อจากเดิม: ป้ายเก่าที่ยังติดกล่องจะสแกนแล้ว "ไม่พบ" ไม่ชนกับป้ายใหม่ (ขึ้นเดือนใหม่เลขเริ่ม 0001 ตามปกติ)
  - ควรทำตอนไม่มีใครรับ/เบิกของ ทุกเครื่องเห็นคลังว่างทันที
- **กู้คืน**: รายการ "ชุดข้อมูลที่ล้างเก็บไว้" → กู้คืน → ยืนยัน
  - ต้องอยู่ในโหมดเดียวกับตอนล้าง และโหมดนั้นต้องยังว่าง (กันข้อมูลสองชุดปนกัน)
  - ถ้ามีข้อมูลใหม่แล้ว: ล้างข้อมูลปัจจุบันเก็บเป็นอีกชุดก่อน แล้วจึงกู้ชุดเดิม (สลับชุดได้)

## 8. ช่องเก็บ (ผัง vs หลังบ้าน)

- จำนวนช่องตามผัง (จำนวนที่วาง × ชั้น) แก้ที่ **ปรับผัง** เท่านั้น
- ช่องชำรุด / ห้ามใช้ → หลังบ้าน → ข้อมูลหลัก → ช่องเก็บ → แตะช่องเพื่อปิด (ระบบไม่แนะนำให้วางของ)
- ช่องพิเศษที่ไม่อยู่ในผัง → ช่องเดียวกัน → **เพิ่มช่องพิเศษ**
- บันทึกผังภายหลังจะไม่เปิดช่องที่ปิดไว้คืน และไม่ลบช่องพิเศษ
- ผังคลัง 2D แสดงช่องที่ปิดเป็นลายเทา · ช่องพิเศษอยู่ใต้หน้า rack ของโซน · กล่องที่รหัสช่องไม่มีในผังแสดงเป็น "กล่องที่ไม่อยู่ในช่องของผัง" ให้สแกน MOVE ย้ายเข้าช่อง
