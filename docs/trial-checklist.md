## 3. งานประจำวันระหว่างทดลอง

1. **รับของ**: ถ่าย Packing List / Invoice → ตรวจจำนวน → ยืนยัน → พิมพ์ป้าย QR (รหัสมี /A /B ระบบตัดเอง)
2. **ใบเบิกย่อย MRA**: เบิกเข้าไลน์ → เลือก Model → ชุดวงล้อ → จำนวนวง → คำนวณ → บันทึก (ตัดสต็อกทันที)
3. **จบวัน FM-P-005**: แท็บ FM-P-005 ยอดรวมจบวัน → ใส่เลขที่เอกสาร → แก้เฉพาะช่องที่ต่าง → บันทึก
4. **ส่ง Planning**: แท็บสรุปส่ง Planning → Export Excel

## 4. ตรวจนับ / อัปเดตยอดคงเหลือ

1. งานคลัง → **ตรวจนับ (Excel)** → เลือกโซน + ระดับ (รายช่องเก็บ แนะนำ) → **ดาวน์โหลดแบบฟอร์ม** (มียอดในระบบให้แล้ว)
2. นับจริง กรอกคอลัมน์ "นับได้" (เว้นว่าง = ไม่ได้นับ, 0 = ไม่มีของ) · เจอของนอกรายการ เพิ่มแถวเอง
3. **อัปโหลดผลนับ** → ตรวจ ขาด / เกิน / ผิด → ใส่หมายเหตุ → **ส่งขออนุมัติ** (ยังไม่ปรับยอด)
4. ผู้มีสิทธิ์อนุมัติแก้ไขยอด (ผู้จัดการ/วิศวกร · ต้องไม่ใช่คนส่ง) → **อนุมัติ → ปรับยอด**
   - ขาด: ลดจากกล่องที่เข้าก่อน · เกิน: เพิ่มเข้ากล่องล่าสุด หรือสร้างกล่องใหม่ (พิมพ์ป้ายที่ ป้าย QR & พิมพ์ เลขเอกสาร CNT)
   - บัญชีคุม FM-P-537 แสดงเป็นบรรทัด "ปรับยอด" อ้างเลข CNT
   - ถ้ามีการเบิก/ย้ายหลังส่งจนยอดไม่พอลด ระบบไม่ให้อนุมัติ ⇒ ไม่อนุมัติแล้วนับใหม่

## 5. สิ้นเดือน

1. วันที่ 1 ของเดือนถัดไป: บัญชีคุม FM-P-537 → เลือก Model + เดือน → **ปิดยอด**
2. Planning และบัญชีเข้าแท็บเดียวกัน (มีตัวเลขแดงเตือน) → **รับทราบ**
3. Export Excel: sheet สรุปมีชื่อผู้ปิดยอดและผู้รับทราบ
4. ต้องแก้ย้อนหลัง → **เปิดเดือนเพื่อแก้ไข** (ระบุเหตุผล) → แก้ → ปิดยอดใหม่ (การรับทราบเริ่มใหม่)

## 6. เริ่มใช้งานจริง แล้วค่อยนำเข้ายอดยกมา

ข้อมูลทดลอง (รอบ 1–3) แยกจากของจริงเด็ดขาด เปลี่ยนเป็นใช้งานจริงแล้วจะเริ่มจากศูนย์ ไม่ต้องลบอะไร
ข้อมูลหลัก (Part, รหัส UAM, BOM, ผู้ใช้, สิทธิ์, หัวหน้าโซน, ผัง) ใช้ชุดเดียวกันทุกโหมด

1. หลังบ้าน → โหมดระบบ → เปลี่ยนเป็น **ใช้งานจริง** (ป้ายมุมบนเป็นสีเขียว "ใช้งานจริง")
2. เริ่มรับของจริง / พิมพ์ป้าย / จัดเก็บ ตามปกติ
3. นำเข้ายอดของที่มีอยู่เดิมเมื่อพร้อม: งานคลัง → ตรวจนับ (Excel) → นับทีละโซน
   - กรอก "นับได้" = **ของทั้งหมดที่อยู่จริง** ในช่อง/โซนนั้น (รวมของที่รับเข้าระบบไปแล้ว) ระบบเพิ่มเฉพาะส่วนที่ขาดให้เป็นกล่องใหม่ เลขเอกสาร CNT
   - ผู้อนุมัติ (คนละคนกับผู้ส่ง) กดอนุมัติ → พิมพ์ป้ายกล่องใหม่ที่ ป้าย QR & พิมพ์ (เลข CNT)
4. ข้อควรระวังระหว่างยังไม่นำเข้ายอดเดิม
   - เบิกของเก่าที่ยังไม่อยู่ในระบบไม่ได้ (ระบบแจ้งสต็อกไม่พอ) ⇒ นำเข้ายอดโซนที่ต้องเบิกบ่อยก่อน
   - บัญชีคุม FM-P-537 แสดงยอดนำเข้าเป็นบรรทัด "ปรับยอด" ในเดือนที่นำเข้า (เดือนถัดไปกลายเป็นยอดยกมา) ⇒ ถ้าทำได้ นำเข้าให้เสร็จในวันแรก ๆ ของเดือน
