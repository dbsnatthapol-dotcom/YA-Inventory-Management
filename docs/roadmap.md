## เป้าหมายปลายทาง

**Digital Twin ของคลังและการส่ง Part เข้าไลน์ประกอบวงล้อ** ของ Union Autoparts Manufacturing (UAM1)

1. ตัวเลขในระบบตรงกับของจริงตลอดเวลา — ทุกการเคลื่อนไหวบันทึกตอนที่เกิด มีเวลา ผู้ทำ และ lot
2. คลังกับฝ่ายผลิตใช้ข้อมูลชุดเดียวกัน มีจุดส่งมอบที่ยืนยันร่วมกัน ไม่ต้องเกี่ยงกัน
3. ใช้จำลองและเตือนล่วงหน้า — ของจะขาดเมื่อไร, rack จะเต็มเมื่อไร, ควรวางของตรงไหน

| ระดับ | ความหมาย | สถานะ |
|---|---|---|
| 1. Digital Model | โมเดล 3D ของโรงงาน + ข้อมูลที่คนกรอก | ✅ |
| 2. Digital Shadow | ข้อมูลหน้างานไหลเข้าระบบทันทีที่เกิด | ⬜ Phase 0–1 |
| 3. Digital Twin | จำลองสถานการณ์ แล้วผลไปปรับการทำงานจริง | ⬜ Phase 2–3 |

## Phase 0 — วางรากฐานให้ใช้งานจริงได้ (1–2 สัปดาห์)

**เสร็จเมื่อ:** พนักงานส่วนนำร่อง login จากมือถือได้, รับเข้าจาก invoice จริงแล้วข้อมูลอยู่ในฐานข้อมูล, ผัง 3D ตรงกับโรงงาน

| Step | งาน | ใครทำ | สถานะ |
|---|---|---|---|
| 0.1 | ยืนยันแผนนี้ + เลือกส่วนนำร่อง (ไลน์ / Model) | 👤 หน้างาน | ✅ ดูด้านล่าง |

| 0.3 | ระบบ login (รหัสพนักงาน) + บทบาท (คลัง / MI3 คัดงาน / ผลิต / วางแผน / ผู้จัดการ / ผู้ดูแลระบบ) + ประวัติเข้าใช้ + สิทธิ์ในฐานข้อมูล | Claude | ✅ ติดตั้งแล้ว · รอทดสอบ login ครั้งแรกบน Vercel |

## Phase 1 — ตัวเลขตรงของจริง: ใบเบิกดิจิทัล (3–4 สัปดาห์)

**เสร็จเมื่อ (ในส่วนนำร่อง):** เบิกผ่านใบเบิก 100%, ไม่มีเบิกด่วนค้างเมื่อจบกะ, ความถูกต้องสต็อก ≥ 98%

| Step | งาน | สถานะ |
|---|---|---|
| 1.1 | ใบเบิกดิจิทัล (ช่องตามใบเบิกกระดาษเดิม) + พิมพ์พร้อม QR | ⬜ |
| 1.2 | คลังจัดของ: ระบบเสนอ lot (มาก่อนจ่ายก่อน, ผ่าน MI3 แล้ว) | ⬜ |
| 1.3 | ยืนยันส่งมอบสองฝ่าย → ตัด BOI เข้า MRA ตามยอดรับจริง | ⬜ |
| 1.4 | เบิกด่วน (ต้องปิดภายในกะ) + หน้าใบเบิกค้าง | ⬜ |
| 1.5 | คืนของจากไลน์ และ NG พร้อมรหัสสาเหตุ | ⬜ |
| 1.6 | นำร่อง 2 สัปดาห์ → ปรับ → ขยายทุกไลน์ | ⬜ |

## ข้อมูลที่ยืนยันแล้วจากหน้างาน

- ฝ่ายผลิตเบิกแล้วยังไม่ลงจำนวน → ตัวเลขสิ้นวันคลาด (ต้นเหตุหลักที่ Phase 1 แก้)
- โรงงานใช้ใบเบิกสินค้าเป็นเอกสารตัดยอดเข้า MRA → เป็นแกนของใบเบิกดิจิทัล
- คลังจัดของจาก BOI ส่งให้ฝ่ายผลิต
- QC MI3 สุ่มตรวจ และอยู่ใต้สายงานฝ่ายผลิต
- ฝ่ายวางแผนออกแผน แต่เปลี่ยนบ่อย บางครั้งฝ่ายผลิตออกแผนเอง

## ความเสี่ยงหลัก
